# Checklist: Fake Store API - Products

## GET /products
- [ ] Успешный запрос возвращает список всех продуктов (код 200 Success)
- [ ] Каждый продукт содержит все ожидаемые поля правильных типов
- [ ] Content-Type в ответе - application/json
- [ ] Негативный запрос возвращает ошибку (код 400 Bad request)
- [ ] Количество элементов соответствует документации

## POST /products
- [ ] Успешный запрос добавляет новый продукт (код 201 Product created successfully)
- [ ] Созданный продукт содержит все ожидаемые поля правильных типов
- [ ] Content-Type в ответе - application/json
- [ ] Негативный запрос возвращает ошибку (код 400 Bad request)
- [ ] Добавление продукта с уже существующим title - проверка обработки дубликата (создаётся новый продукт с уникальным id, либо возвращается ошибка о дублировании)

## GET /products/{id}
- [ ] Успешный запрос возвращает продукт с соответствующим id (код 200 Success)
- [ ] Продукт содержит все ожидаемые поля правильных типов
- [ ] Content-Type в ответе - application/json
- [ ] Негативный запрос возвращает ошибку (код 400 Bad request)

## PUT /products/{id}
- [ ] Успешный запрос на изменение продукта по соответствующему id возвращает продукт с корректно изменённым(ми) полем(ми) (код 200 Product updated successfully)
- [ ] Продукт содержит все ожидаемые поля правильных типов
- [ ] Content-Type в ответе - application/json
- [ ] Негативный запрос возвращает ошибку (код 400 Bad request)

## DELETE /products/{id}
- [ ] Успешный запрос на удаление корректно удаляет продукт (код 200 Success)
- [ ] Негативный запрос возвращает ошибку (код 400 Bad request)
